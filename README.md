# Isolation: Last Floor — обновления

**Isolation: Last Floor** («Изоляция: Последний этаж») — экшен-выживание от первого лица на Godot 4.
Отряд спецназа спускается по этажам закрытого комплекса BioTech (−1 … −10), где люди сошли с ума от сыворотки.
Рукопашка, захваты и добивания, мало патронов, лут, хранилища с кодовыми замками, психика бойца, кооп по локалке до 4 игроков.
Платформы: Android и Windows.

## Что в этом репозитории

Только файлы автообновления — кода и исходников игры здесь нет.

| Файл | Что это |
|---|---|
| `manifest.json` | номер текущей сборки и основы, список патчей с размером и SHA-256 |
| `android/patch_N.pck` | патчи для Android |
| `windows/patch_N.pck` | патчи для Windows |

## Как обновляется игра

1. Во время заставки игра скачивает `manifest.json`.
2. Докачивает недостающие патчи по порядку и сверяет каждый с SHA-256.
3. Сразу подключает их (сохраняются в папке игры `patches/`). Если не хватало промежуточного патча, ПК-версия перезапускается сама, а на телефоне нужно закрыть и открыть игру.

Без интернета игра запускается с тем, что уже скачано.
Вручную проверить обновление: планшет в кабинете → «Обновление» → «Проверить».

## Когда нужно скачать игру заново

Патч ставится только поверх своей **основы**. Когда выходит новая основа, игра пишет «Вышла новая основа игры — скачай игру заново». Тогда поставь свежий APK или exe.

Текущая основа — **сборка 12**: с неё патчами обновляется вся игра, включая сетевой модуль и настройки.

## Кооп

Для игры вместе у всех должна быть одна и та же сборка: игра с другой версией не пустит и объяснит почему.
Играть нужно в одной сети (Wi-Fi или точка доступа). Брандмауэр Windows должен пропускать игру в частной сети, а VPN — отключён или с разрешённой локальной сетью.
